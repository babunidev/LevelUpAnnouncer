# LevelUpAnnouncer — concept

**By Babuni**

The idea represented by my original BuxbrewDing addon is to make each level-up a small roleplay event. Instead of treating progression as a number alone, the addon gives each level from 1 to 60 its own guild announcement. The text collection moves from early adventures toward exaggerated heroic confidence.

The existing source supports automatic announcements, private previews and manually requested guild messages. This describes what the code contains, not a fresh gameplay verification or a recovered transcript of my original design discussions.

I renamed the GitHub project **LevelUpAnnouncer** to make its purpose clearer. Its installed addon files and commands still carry the historical BuxbrewDing name.
